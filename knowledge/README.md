# Biblioteca inicial de conhecimento

Estes Markdown são orientações e templates, não pesos nem uma concessão de capacidades. Importe seletivamente no projeto correto pelo CLI documentado em `docs/FOUNDATION.md`, com o servidor parado. Não preencha templates com dados reais neste repositório público.

`core/` define identidade, processo e qualidade; `skills/` reúne procedimentos de código e criação visual; `templates/` padroniza contexto e experiências. O carregador usa manifesto privado com hash e escopo. YAML não se autoaprova, Markdown não executa comandos, e importação nunca autoriza treinamento.

Revise cada nota quando mudar a API, o contrato ou a versão que a sustenta. Uma hipótese deve ser marcada como hipótese; evidências devem identificar revisão/arquivo/linhas. Remover o documento original não remove automaticamente seus derivados históricos.
