# Logo do Orbit: Identidade visual com evidência

Essas regras visam criar ou melhorar a logo do Orbit.

Para criar uma identidade visual com base em evidências, siga estes passos:
1. **Entenda o produto e o público**. Defina o propósito e o público-alvo para alinhar o design.
2. **Estude marcas concorrentes**. Analise princípios de design, cores e tipografias, mas evite copiar desenhos.
3. **Crie um SVG simples**. Use ferramentas como Inkscape ou código manual para garantir controle sobre elementos.
4. **Compare descrição com o desenho renderizado**. Verifique se os elementos (como círculos, traços) correspondem às especificações.
5. **Preserve originais e hashes**. Mantenha versões não editadas e hashes para rastrear alterações.
6. **Aceite críticas e corrija falhas**. Revisões externas são essenciais para evitar erros de concepção.

**Verifique limites de círculos**:
Os limites horizontais do círculo são `cx - r - w/2` e `cx + r + w/2` (largura do traço: w). Os limites verticais são `cy - r - w/2` e `cy + r + w/2`.
- A circunferência tem comprimento `2πr`.
- Para traços interrompidos, considere abertura e pontas arredondadas.

**Renderize apenas em navegador dentro de Docker Linux**. (Verifique que o isolamento está configurado corretamente.) Se não disponível, interrompa a execução no Windows.
Teste com 16, 24, 32 e 64 pixels, usando fundos claros/escuros e uma única cor.
Aplicar a marca em login, barra lateral, ícones e anúncios, com descrição acessível.

Importar esta lição oferece consulta, não altera pesos. Não comprova autonomia, reconhecimento comercial ou exclusividade mundial. Não declare que a marca final passou em testes ainda não feitos.
