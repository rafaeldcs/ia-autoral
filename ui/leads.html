Seu site conectado ao servidor local

O backend do site envia eventos autenticados para uma fila HTTPS. Esta máquina busca os eventos e confirma o recebimento depois de gravá-los. Não é necessário abrir o aplicativo local para a internet.

  1. Configure a fila no servidor do seu site, atrás de HTTPS.
  2. Mantenha as chaves de integração no backend, nunca no navegador do visitante.
  3. Ative o coletor local para este projeto. Ele pode permanecer buscando eventos.

Meta e WhatsApp precisam de adaptadores oficiais de entrada e configuração de conta. Informar essas origens em um evento não comprova uma conexão real.

Leia docs/LEADS_LOCAL.md no pacote instalado para comandos, formato e teste da conexão. Nenhuma mensagem é enviada por esta tela.

Conexão da fila deste projeto

A chave fica protegida no usuário Windows do servidor. Atualize esta tela para conferir a última busca. Sem conexão configurada, nenhum serviço externo é consultado.
