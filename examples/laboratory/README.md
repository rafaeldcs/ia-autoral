# Projeto local de laboratório

Cadastre esta pasta no LocalAuthor para experimentar leitura, consulta e revisão.
Não a use como corpus de treinamento por padrão: este exemplo foi gerado nesta conversa,
e não possui aprovação específica de uso para destilação ou treinamento de modelo concorrente.
A aplicação não transforma código importado em dados de treinamento automaticamente.

O método `SetQuantity` já bloqueia estoque negativo. Uma tarefa manual possível é melhorar
a mensagem ou adicionar um método de entrada de estoque, sempre revisando a proposta.
O projeto não depende de NuGet externo, mas a compilação C# não foi executada nesta sessão.
